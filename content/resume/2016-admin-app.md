Mphasis needed a React web app to manage dynamic resources sitting on a complex
database. I bootstrapped the project and led the front-end, but the constraint
that shaped everything was the team, not the app: developers spread between
France and India, most of them new to React, to React Native Web, and to modern
JavaScript itself.

A codebase people are learning on is not the codebase you would write alone.
The architecture went to React Native Web for one explicit component model
rather than a set of conventions to absorb; Flow made types a compiler's
problem instead of a reviewer's; Jest with snapshots turned "did I break
something?" into a command anyone could run without asking me. Guardrails
first, so the team could move at its own pace instead of at mine.

The rest was daily. Code review every day, less to catch mistakes than to
explain them: the fastest way I know to make a team that is new to a stack
stop being new to it.

Mphasis avait besoin d'une application web React pour gérer des ressources
dynamiques adossées à une base de données complexe. J'ai démarré le projet et
dirigé le front-end, mais la contrainte qui a tout façonné, c'était l'équipe,
pas l'application : des développeurs répartis entre la France et l'Inde, pour
la plupart nouveaux sur React, sur React Native Web et sur le JavaScript
moderne lui-même.

Une base de code sur laquelle des gens apprennent n'est pas celle qu'on
écrirait seul. L'architecture est passée par React Native Web pour offrir un
modèle de composants explicite plutôt qu'un jeu de conventions à absorber ;
Flow a fait des types l'affaire du compilateur et non celle du relecteur ; Jest
et ses snapshots ont transformé « est-ce que j'ai cassé quelque chose ? » en
une commande que chacun pouvait lancer sans me la demander. Des garde-fous
d'abord, pour que l'équipe avance à son rythme et non au mien.

Le reste était quotidien. Une revue de code chaque jour, moins pour repérer les
erreurs que pour les expliquer : le moyen le plus rapide que je connaisse pour
qu'une équipe qui découvre une stack cesse de la découvrir.
