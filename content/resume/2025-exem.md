Built a web application for visualizing electromagnetic field (EMF) data on interactive city maps. Features include site planning tools, cartography layers, measurement clustering, and data exploration panels. Auto-generated API types from OpenAPI specs, i18n support, and a full Storybook-driven component library.

Développement d'une application web de visualisation des données de champs électromagnétiques (EMF) sur des cartes interactives urbaines. Fonctionnalités : outils de planification de sites, couches cartographiques, clustering de mesures et panneaux d'exploration de données. Types API auto-générés depuis des spécifications OpenAPI, support i18n et bibliothèque de composants pilotée par Storybook.
