Lyv Endo helps women living with endometriosis and is certified as a medical
device, so every release ships with its regulatory paperwork. Most of it was
typed by hand from information git already had, and the verification plan was
run manually.

From now on, everything will come from the repositories: one command generates
the release pack (release candidate, regulatory release, UDI, List of SOUP, SBOM and
vulnerability audit, release note) and keeps a text copy of each document, so
the diff with the previous release shows exactly what to re-read and re-sign.
Validated by regenerating a release already signed; the team now adopts it
document by document, starting with the List of SOUP.

On the test side, 40 Maestro scenarios (110 targeted) run the verification plan on iOS and
Android, locally or in CI from a `/e2e` comment on a pull request. Alongside, a few
fixes for recurring issues.

Côté tests, 40 scénarios Maestro (objectif 110) jouent le plan de vérification sur iOS et
Android, en local ou en CI depuis un commentaire `/e2e` sur une pull request.
En parallèle, quelques correctifs de problèmes récurrents.
