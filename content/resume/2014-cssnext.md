I created cssnext in 2014 - a PostCSS plugin pack that let developers write
tomorrow's CSS syntax today (variables, custom properties, nesting, color
functions…) and transpile it for every browser. Think "Babel for CSS." It grew
to millions of weekly downloads and now lives on as postcss-preset-env, still
maintained today.

I built a plugin architecture orchestrating dozens of CSS transformations, a
configuration system targeting specific browsers, and a release process
maintaining backward compatibility across hundreds of versions.

Hardest parts: API design at scale (every default affects thousands of
projects), interpreting W3C specs written for browser implementers, and handing
the project off to a worthy successor.

Building for an ecosystem teaches discipline client work rarely does - when
other developers depend on your defaults and semver, you think carefully about
every decision. I bring that rigor to every client project I architect.

J'ai créé cssnext en 2014 — un ensemble de plugins PostCSS qui permettait
d'écrire dès aujourd'hui la syntaxe CSS de demain (variables, custom
properties, imbrication, fonctions de couleur…) et de la transpiler pour tous
les navigateurs. Un « Babel du CSS ». Le projet a atteint des millions de
téléchargements hebdomadaires et se poursuit aujourd'hui sous le nom
postcss-preset-env, toujours maintenu.

J'ai construit une architecture de plugins orchestrant des dizaines de
transformations CSS, un système de configuration ciblant des navigateurs
précis, et un processus de publication garantissant la rétrocompatibilité sur
des centaines de versions.

Les parties les plus difficiles : concevoir une API à cette échelle (chaque
valeur par défaut touche des milliers de projets), interpréter des
spécifications W3C écrites pour ceux qui implémentent les navigateurs, et
transmettre le projet à un successeur digne de ce nom.

Construire pour un écosystème impose une discipline que le travail client
apprend rarement : quand d'autres développeurs dépendent de vos valeurs par
défaut et de votre semver, chaque décision se pèse. Cette rigueur, je
l'emmène dans tous les projets clients dont je conçois l'architecture.
